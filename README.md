# how-rnn-dropout-works

드롭아웃은 왜 순환 연결을 피해 가는가 — 「드롭아웃을 층 사이의 비순환 연결에만 배타적으로 적용하고, 시간에 걸쳐 메모리를 보존하는 수평 방향의 순환 연결에는 절대 적용하지 않는다」는 한 문장이 왜 결정적인지를 브라우저에서 직접 세어 보는 인터랙티브 교육 자료입니다.

**🔗 데모: https://dev-jonghoonpark.github.io/how-rnn-dropout-works/**

원 논문: [Recurrent Neural Network Regularization](https://arxiv.org/abs/1409.2329) (Zaremba, Sutskever & Vinyals, arXiv:1409.2329 · ICLR 2015 투고) · 저자 구현: [wojzaremba/lstm](https://github.com/wojzaremba/lstm)

## 한 문단 요약

RNN을 시간 축으로 펼치면 격자가 됩니다. **세로(비순환) 연결**은 같은 시각 안에서 아래층 표현을 위층으로 올리고, **가로(순환) 연결**은 기억을 시간 축으로 나릅니다. 정보 하나가 세로 연결을 지나는 횟수는 망의 깊이로 고정(**L+1번**)되지만, 가로 연결을 지나는 횟수는 기억해야 할 시간에 비례해 무한정 늘어납니다(**Δt번**). 그래서 드롭아웃을 가로에 걸면 경로 생존 확률이 `(1−p)^(L+1+Δt)`로 지수 붕괴합니다 — p=0.5, 35스텝 언롤이면 `3.6×10⁻¹²`. 세로에만 걸면 정규화 효과는 온전히 얻으면서 기억 능력은 그대로 남습니다.

## 이 페이지가 답하는 질문

- "수평 방향의 순환 연결"이 정확히 어떤 연결인가?
- 왜 하필 **L+1**번인가? 왜 그 횟수가 타임스텝 수와 무관한가?
- 순환 연결에 드롭아웃을 걸면 구체적으로 무슨 일이 일어나는가?
- PyTorch `nn.LSTM(dropout=0.5)`만 쓰면 논문 기법이 재현되는가? (절반만)
- 그럼 순환 연결에는 영영 드롭아웃을 못 거는가? (Gal & Ghahramani, Zoneout)
